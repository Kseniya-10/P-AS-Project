# Прогнозно-аналитическая система цены предложения недвижимости

Система анализирует 50 000 объявлений вторичного рынка Москвы из
`../secondary_market.csv`, присоединяет исторические показатели качества воздуха
Open-Meteo и формирует витрину для прогноза цены предложения за 1 м².

## Запуск

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
pip install -r requirements.txt
python -m pipeline run
python -m streamlit run app.py
```

Для первого запуска нужна сеть: система получает данные о PM10, PM2.5, NO₂ и O₃.
Повторная загрузка продолжает ряд качества воздуха с перекрытием в два дня;
`python -m pipeline run --stage transform` пересобирает витрины без сетевого запроса.
`python -m pipeline status` показывает журнал загрузки. Пути и параметры API находятся
в `config/config.yaml`, каталог CSV можно переопределить переменной `PAS_DATA_DIR`.

## Источники и качество воздуха

Объявления читаются из CSV с полями характеристик объекта, координатами, датой
публикации и `price_per_sqm`. Цель модели — именно цена предложения из объявления,
а не цена закрытой сделки.

Ссылка `https://archive-api.open-meteo.com/v1/archive` относится к исторической
погоде и не предоставляет загрязнители воздуха. Поэтому для внешнего фактора
используется исторический endpoint Open-Meteo Air Quality:
`https://air-quality-api.open-meteo.com/v1/air-quality`. Система запрашивает почасовые
PM10, PM2.5, NO₂ и O₃ и вычисляет среднее за день. Точка запроса — центр Москвы
(координаты задаются в `config/config.yaml`), данные связываются с объявлениями
по предшествующему дню, чтобы модель не использовала измерения, сделанные позже
публикации объявления.

Чтобы ограничивать размер запросов, архив загружается интервалами по 30 дней.
Успешные данные сохраняются в CSV и при повторном запуске не загружаются заново,
кроме двухдневного перекрытия. `--full-refresh` повторно загружает весь период.
Период фактической доступности архивных данных зависит от выбранного загрязнителя
и покрытия Open-Meteo; пропуски остаются пустыми, а не подменяются нулями.

## Слои и витрины

| Слой | Назначение |
|---|---|
| `data/raw/properties.csv` | исходные объявления |
| `data/raw/air_quality.csv` | дневные средние загрязнителей |
| `data/stg/properties.csv` | объявления после проверки дат, координат, площади и цены |
| `data/stg/properties_rejected.csv` | отклонённые записи и причины |
| `data/mart/property_training.csv` | характеристики недвижимости, цена и показатели воздуха |
| `data/mart/monthly_price.csv` | средняя и медианная цена предложения по месяцам |
| `data/mart/air_quality_daily.csv` | дневной ряд показателей воздуха |

Дашборд показывает распределение и динамику рынка, ряд загрязнителей и оценку
Random Forest. Модель тестируется на более позднем временном отрезке (последние 20%
дат публикации); отображаются MAE, RMSE и R². Значения метрик характеризуют
ретроспективную проверку и не гарантируют точность будущего прогноза.

## Команды

```bash
python -m pipeline run --sources properties
python -m pipeline run --sources air_quality
python -m pipeline run --stage transform
python -m pipeline run --full-refresh
python -m pipeline status
pytest -q
```
